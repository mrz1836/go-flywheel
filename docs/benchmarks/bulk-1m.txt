Each run is one BulkJobs call: a forced retry (Retry.Force) of one cohort's discarded jobs,
Query{Kinds: [cohort], States: [discarded]}, in batches of 500 with MaxJobs at the cohort's size,
timed whole by the wall clock. A batch's time runs from the start of its read to the start of the
next batch's read, or to the call's return for the last, so it holds the read and, for an apply, the
batch's transaction: the locked re-read, the update, the audit entries, and the commit. After an
apply, its cohort is reset to discarded, job_audit truncated, and jobs vacuumed, so every run starts
from the same table. "with" runs with jobs_explore_kind installed from ExplorerIndexSet; "without"
drops it and analyzes jobs. Each plan is one batch's read past the first batch's cursor, explained
with EXPLAIN (ANALYZE, BUFFERS) against the cohort as the run read it.
